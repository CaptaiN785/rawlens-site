Privacy Policy

Markdown Viewer (browser extension) · Last updated 26 August 2026

Summary: Markdown Viewer does not collect, transmit, or share any of your data. It makes no network requests. The only thing it stores is which theme you picked.

What the extension stores

One setting: the name of the theme you chose (for example github-dark). It is kept in your browser's extension storage and, if you are signed into the browser, synced by the browser to your other devices the same way your other extension settings are. Nothing else is stored — not the files you open, not their names, not your history.

What the extension sends

Nothing. There is no server, no account, no analytics, no crash reporting, and no telemetry. The extension makes no outbound network requests of any kind.

What the extension reads

To render a Markdown file, the extension reads the text of the page you opened — only when that page is a raw Markdown file (a .md address showing plain text). The text is converted to formatted HTML entirely on your device and never leaves it. Pages that are not raw Markdown files are left untouched, and nothing about them is read or recorded.

If a Markdown file references an image by URL, your browser fetches that image when the rendered page displays it — exactly as it would on any web page. The extension itself requests nothing.

Local files

Rendering files on your own disk (file:// addresses) works only if you enable "Allow access to file URLs" for this extension in your browser's settings. That grant is used solely to read the Markdown file you chose to open.

Deleting your data

Removing the extension deletes its stored setting. There is nothing else to delete.
