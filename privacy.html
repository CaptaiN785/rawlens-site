Privacy Policy

Rawlens — Markdown, JSON & CSV Viewer (browser extension, formerly "Markdown Viewer") · Last updated 20 September 2026

Summary: Rawlens does not collect, transmit, or share any of your data. It makes no network requests. The only thing it stores is which theme you picked.

What the extension stores

One setting: the name of the theme you chose (for example github-dark). It is kept in your browser's extension storage and, if you are signed into the browser, synced by the browser to your other devices the same way your other extension settings are. Nothing else is stored — not the files you open, not their names, not your history.

What the extension sends

Nothing. There is no server, no account, no analytics, no crash reporting, and no telemetry. The extension makes no outbound network requests of any kind.

What the extension reads

The extension renders raw Markdown, JSON, and CSV. Because a JSON response can live at any address, a small check runs on each page you open: it looks at the page's content type and whether the browser is showing it as plain text. For an ordinary web page that is all it does — the page's content is not read, changed, or recorded.

Only when the page is a raw text document does the extension read its text: to render it if it is Markdown, JSON, or CSV, and — for a plain-text page with no recognisable file extension — to test whether it is JSON. That happens entirely on your device; the text never leaves it, and nothing about it is stored.

So that CSV files can be displayed at all, the extension changes one response header (Content-Type) on top-level navigations to CSV files, which makes the browser show the file instead of downloading it. Files a site marks as downloads are left alone. No content is read or sent anywhere by this rule.

The Open a file page (the toolbar icon) reads a file you pick or drop, in that page, to render it. It is not uploaded or stored.

If a Markdown file references an image by URL, your browser fetches that image when the rendered page displays it — exactly as it would on any web page. The extension itself requests nothing.

Permissions, and why

  • Storage — remembers your theme. The only value stored.
  • Scripting — loads the viewer into a tab, only after the check above has confirmed the tab is a raw Markdown, JSON, or CSV document. This keeps the viewer's code off every ordinary page.
  • Declarative Net Request — the single CSV header rule described above. It blocks and redirects nothing.
  • Access to all sites and file URLs — a JSON response, a Markdown file, or a CSV can live at any address, so the check cannot be limited to a list of sites.

Local files

Rendering files on your own disk (file:// addresses) works only if you enable "Allow access to file URLs" for this extension in your browser's settings. That grant is used solely to read the file you chose to open.

Deleting your data

Removing the extension deletes its stored setting. There is nothing else to delete.
